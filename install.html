Four steps. Then you’re ready.

Install it once in each browser where you want to use PageLens.

01

Download the ZIP

Choose Download PageLens above. Your browser saves a ZIP file to Downloads.

02

Extract the folder

On Windows, right-click the ZIP and choose Extract All. On Mac, double-click it. Keep the extracted folder somewhere you can find again.

03

Open extensions

Open your browser’s extensions page. Turn on Developer mode, then choose Load unpacked.

04

Select the PageLens folder

Choose the extracted folder that has manifest.json directly inside it, then click Select Folder. Pin PageLens from the puzzle-piece menu if you like.

i
The folder is what you select—not manifest.json.

In the folder picker, manifest.json may not appear as a selectable item. Select the PageLens folder itself. If the ZIP extracted into an extra folder, open folders until you find the one with manifest.json inside.

Quick help

A couple of common questions.

If something looks different in your browser, these quick fixes usually point you to the right folder or page.

The folder picker looks empty. What should I choose?

Choose the extracted PageLens folder; do not try to open or select the manifest file. Use the folder where manifest.json is visible when you view its contents in File Explorer.

I see “Upload package” instead of “Load unpacked.”

For local installation, open the browser’s extensions page, enable Developer mode, and choose Load unpacked. “Upload package” is for a store submission and is not the local install step.

How do I update an existing installation?

Either replace the files in the same folder that PageLens already loads from, then click Reload, or remove PageLens and load the newly extracted folder. Reloading alone will keep using the old folder.

Why is a tool unavailable in the live preview?

The preview runs PageLens on a sample page. Browser-only screenshot capture and responsive reference capture need the installed extension. Browser settings and store pages block page tools too.

Your page stays on your device.PageLens does not send page content to a PageLens server. Optional font and asset requests go directly to their source.
