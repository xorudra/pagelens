Thirteen tools for the details that matter.

Pick one component, collect a full-page reference, or test how a new design direction feels.

01 Inspect

Pick element

Preview and copy a selected element’s HTML and computed CSS.

Inspect & measure

Check dimensions, spacing, styles, and distances on the page.

Extract colors

Collect a palette of the colors used throughout the page.

Detect fonts

See font family, size, weight, and line height on hover.

02 Collect

Clone page

Preview a rendered snapshot and inspect highlighted code in its ZIP.

Extract assets

Find images, SVGs, video, and page backgrounds.

Design MD

Save page colors, typography, and spacing as a reference.

Design prompt

Build a detailed, editable brief for your next design.

03 Experiment

Edit text

Preview your own copy and see how it fits in the layout.

Swap fonts

Try another typeface on headings, body text, or an element.

Screenshot

Capture, crop, annotate, and export a page or element.

Responsive viewer

Compare multiple viewport widths side by side.

Move & delete

Rearrange or remove elements and undo your changes.

Code you can actually inspect
